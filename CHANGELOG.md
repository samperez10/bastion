# Changelog

## v0.1.0-alpha.16

- Added responsive portrait and landscape layouts for workspace dashboards and attached agent panes.
- Redesigned pane headers, workspace tabs, pane controls, and touch targets for compact Android screens.
- Added compact, scroll-aware session resume and pane-switching menus.
- Added durable tab rename and deletion with active-pane and last-tab safety checks.
- Improved terminal scrollback, live-position recovery, color rendering, pane status, and touch interaction.
- Prevented menu input from leaking into background agents and fixed stale popup rendering during active output.
- Removed obsolete prototype code and duplicate terminal dependencies.
